PEIS Founding Beta Program

We are accepting a limited number of qualified organizations and professionals interested in evaluating PEIS on controlled, real-world project use cases.

Program Guidelines & Manual Intake Protocol

  • Application-Based Qualification: Every application is reviewed manually by our evaluation committee. Submission of an application does not guarantee participation.
  • No Automatic SaaS Accounts: Phase 1 does not feature instant public logins or unmanaged self-service account generation.
  • Strict Data Governance Boundary: DO NOT submit project documents, confidential records, proprietary customer information, Controlled Unclassified Information (CUI), classified information, Protected Health Information (PHI), credentials, passwords, API keys, or other sensitive project evidence through this public form.
  • Separate Controlled Onboarding: Actual project-data transfer, if later authorized, will occur through a separate controlled onboarding process under executed Non-Disclosure and Data Security Agreements.
